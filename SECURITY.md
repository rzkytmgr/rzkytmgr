# Security Policy

This is a personal portfolio site built with Next.js. The site stores no user
accounts and no personal data, but we still take security seriously —
including dependency vulnerabilities and anything that could affect visitors.

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report vulnerabilities privately by email to:

```text
rzkytmgr@gmail.com
```

Include as much of the following as possible:

- A description of the vulnerability
- The affected component or dependency and its version
- Steps to reproduce the issue
- The potential impact
- A suggested fix, if you have one

## What happens next

- You will receive an acknowledgment within 48 hours
- The report will be assessed and a fix will be prepared
- Details are kept private until the issue is resolved, following a
  coordinated disclosure process

## Supported versions

Only the latest version on the `main` branch is supported. If you are running
an older version, please update before reporting an issue.
