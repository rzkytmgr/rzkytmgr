# Building a Scalable REST API with NestJS

This experiment explored how to structure a backend application using a modular architecture that remains maintainable as the codebase grows. The primary objective was to establish clear boundaries between business logic, infrastructure, and presentation layers while keeping the API easy to extend.

Authentication was implemented using JWT alongside role-based authorization to secure protected resources. Request validation, centralized exception handling, and database abstraction through Prisma helped create a predictable development experience and simplified future feature development.

The project also included Docker support to ensure a consistent local development environment and straightforward deployment across different platforms. Overall, this experiment served as a practical reference for building production-ready backend services with NestJS.
