# FinTrack Expense Tracker

FinTrack adalah aplikasi pencatatan keuangan pribadi yang membantu pengguna memonitor pemasukan, pengeluaran, serta kondisi finansial secara keseluruhan melalui visualisasi data yang informatif.

Aplikasi menyediakan fitur kategorisasi transaksi, ringkasan bulanan, grafik pengeluaran, hingga pencarian histori transaksi. Seluruh data disimpan menggunakan Supabase sehingga sinkronisasi dapat dilakukan secara real-time.

Meskipun proyek ini telah diarsipkan karena digantikan oleh versi terbaru, FinTrack menjadi fondasi penting dalam mempelajari autentikasi, manajemen database, serta implementasi dashboard analitik berbasis web.
