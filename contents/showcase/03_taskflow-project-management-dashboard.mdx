# TaskFlow

TaskFlow adalah aplikasi manajemen proyek yang dirancang untuk membantu tim mengelola pekerjaan secara efisien melalui tampilan Kanban yang intuitif. Pengguna dapat membuat proyek, mengatur task, menetapkan deadline, dan berkolaborasi dengan anggota tim secara real-time.

Aplikasi ini dibangun menggunakan Next.js dengan TypeScript untuk memastikan performa yang optimal dan pengalaman pengembangan yang lebih baik. Backend menggunakan Prisma ORM yang terhubung ke PostgreSQL sebagai database utama.

Selama pengembangan, fokus utama adalah membangun antarmuka yang responsif, mudah digunakan, serta menerapkan struktur kode yang scalable untuk memudahkan pengembangan fitur di masa mendatang.
