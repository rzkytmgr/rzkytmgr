# DevNotes Knowledge Base

DevNotes adalah aplikasi pencatatan berbasis Markdown yang dibuat untuk mengelola dokumentasi teknis, catatan pembelajaran, serta kumpulan referensi dalam satu tempat. Seluruh konten dapat ditulis menggunakan Markdown sehingga proses penulisan menjadi sederhana dan mudah dipelihara.

Proyek ini menggunakan Contentlayer untuk menghasilkan konten statis secara otomatis dari kumpulan file Markdown. Dengan pendekatan ini, setiap catatan dapat diproses menjadi halaman yang cepat, memiliki metadata yang lengkap, dan mudah diindeks oleh mesin pencari.

Selain mendukung pencarian dan navigasi yang cepat, aplikasi juga menghadirkan antarmuka yang bersih dengan animasi ringan menggunakan Framer Motion. Fokus utama proyek ini adalah memberikan pengalaman membaca yang nyaman sekaligus mempermudah pengelolaan dokumentasi untuk penggunaan jangka panjang.
