# Personal Portfolio V2

Personal Portfolio V2 merupakan pengembangan dari versi sebelumnya dengan pendekatan yang lebih modern dan berorientasi pada performa. Website ini berfungsi sebagai tempat untuk menampilkan proyek, pengalaman kerja, serta artikel teknis yang ditulis secara berkala.

Website memanfaatkan Astro sebagai framework utama sehingga halaman statis dapat dimuat dengan sangat cepat. Integrasi React hanya digunakan pada komponen yang benar-benar membutuhkan interaktivitas.

Selain peningkatan performa, proyek ini juga berfokus pada kemudahan pengelolaan konten menggunakan MDX sehingga penambahan artikel dan proyek baru dapat dilakukan tanpa mengubah struktur aplikasi.
